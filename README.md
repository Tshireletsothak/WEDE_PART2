SEO Answers: 
SEO-Search engine optimization includes improving  a website to increase it's appearance and real in search engine result pages. 
Purpose in web development: It ensures that a website is physically stable, easily accessed by search engine bots, and available to specified users. 
How SEO practices can improve UX and website performance: 
UX and performance: Best SEO methods are directly connected with productive user experience, focusing on fast page loading speeds, mobile-friendly designs, ordered layout structures and easy-to use  navigation. 
Outcome: Improving main web standards and content distribution ensures limited exit levels and ensures that users can easily find and interact with content. 
Advantages of implementing SEO on a website: Productive SEO produces permanent authentic traffic separately of advertised promotions, promoting lasting reliability and trust among users. It also expands brand exposure, improves site usability and boosts change levels by targeting appropriate consumers intentions. 
Explain and demonstrate specific SEO techniques using HTML,CSS and javascript where applicable: 
HTML/CSS: Uses functional tags such as header, footer and section to clearly describe information structure for search engines. Make sure CSS is compressed to improve loading times. 
Javascript: When creating dynamic single-page apps or components, utilize server-side rendering that allows search engine bot to successfully record changing uploaded content. 
Purpose of HTML meta element along relevant examples: 
Meta elements occur in the head section of an HTML file to provide search engines and browsers with metadata about the webpages content, creator and functionality. 
Examples: <meta name="description" content="A short summary of the webpage content displayed in search results.">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
